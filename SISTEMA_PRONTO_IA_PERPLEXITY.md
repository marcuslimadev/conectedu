## 🧪 **COMO TESTAR COM IA PERPLEXITY**

### **Acesso ao Sistema**
1. **URL**: `http://localhost/conectedu/frontend/`
2. **Login**: Use credenciais válidas
3. **Painel**: Aparece automaticamente (barra roxa no topo)

### **Comandos de Teste Rápido**
```javascript
// Console do navegador (F12)
DEV.validarSistema()        // Validação completa
DEV.criarAlunos()          // Criar base de dados
DEV.preencherFormularios() // Preencher tudo
```

### **Botões de Interface**
- 🎯 **"👥 Criar 5 Alunos"** → Cria base completa de dados
