## 📝 Notas Importantes

### Tecnologias Utilizadas
- **Frontend**: HTML5, CSS3 (sem Bootstrap), JavaScript (ES6+)
- **Framework JS**: Vue.js 3 + Vue Router 4
- **Gráficos**: Highcharts
- **HTTP Client**: Axios
- **Backend**: PHP com API REST
- **Banco de dados**: MySQL
- **PDF**: mPDF

### Funcionalidades Principais
1. **Gestão de Alunos**: Cadastro, edição, listagem com limites por modalidade
2. **Gestão de Cursos**: Sistema completo de cursos e disciplinas
3. **Agenda**: Calendário integrado para agendamentos
4. **Formulários AEE**: Entrevista, PDI, PAI digitais
5. **Planejamento**: Diário de bordo e planos semanais
6. **Frequência**: Controle de presença/ausência
7. **Relatórios**: Geração de relatórios em PDF
8. **Administração**: Gestão de usuários e permissões
